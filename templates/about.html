About the Project

This sign language recognition system was developed to bridge the communication gap between the deaf/hard-of-hearing community and those who don't know sign language.

Technology Stack

This project uses:
  • MediaPipe: For real-time hand tracking and landmark detection
  • TensorFlow: To train and run the LSTM model for gesture recognition
  • Flask: Web framework for the application
  • OpenCV: For camera feed processing and visualization
  • Bootstrap: Frontend framework for responsive design
Model Architecture:

The recognition model uses a sequence-based LSTM (Long Short-Term Memory) neural network architecture to analyze temporal hand movement patterns. It processes 30 frames of hand landmark data to make predictions.

How It Works

  1. Capture: The system captures video frames from your webcam in real-time
  2. Hand Detection: MediaPipe identifies hand landmarks (21 points per hand)
  3. Feature Extraction: The system extracts relevant features from the landmarks
  4. Sequence Analysis: An LSTM model analyzes the sequence of landmarks over time
  5. Classification: The model predicts which sign is being performed
  6. Display: The result is shown on screen with a confidence score

The model was trained on multiple examples of each sign, performed with variations to improve robustness.

Future Improvements

This project is constantly evolving. Some planned improvements include:

  • Adding more signs to the vocabulary
  • Improving model accuracy and robustness
  • Adding sentence-level recognition for continuous signing
  • Developing a mobile application version
  • Supporting different sign languages (currently focused on ASL)
  • Adding text-to-sign translation capabilities

Note: This project is intended for educational and demonstration purposes. For critical communication needs, please consult with professional sign language interpreters.
